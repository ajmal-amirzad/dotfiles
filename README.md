# Personal Dotfiles

This repository contains my personal **dotfiles and development environment configurations**. It serves as a collection of the tools, settings, scripts, and configurations I use to set up and maintain my development environment.

Each directory is self-contained and may have its own setup instructions, dependencies, and notes. **For installation or configuration instructions, refer to the `README.md` inside the respective directory.**

These configurations are primarily tailored to my workflow, so some adjustments may be required depending on your operating system, hardware, or preferences.

> **Tip:** Start by exploring the directory you're interested in and follow its accompanying `README.md` before applying any configuration.

Feel free to use, adapt, or borrow anything that is useful for your own setup.
